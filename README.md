# homoclinic-orbits 
[![CI](https://github.com/djps/homoclinic-orbits/actions/workflows/makefile.yml/badge.svg)](https://github.com/djps/homoclinic-orbits/actions/workflows/makefile.yml)

Shooting and continuation of homoclinic orbits as localised solutions of cosserat rods.

There are two directories: shooting and continutation.

The continuation software `auto07` must be installed from github: [here](https://github.com/auto-07p/auto-07p) in order to generate bifurcation diagrams.
